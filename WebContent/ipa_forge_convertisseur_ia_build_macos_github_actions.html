    3 Compilation macOS via GitHub Actions

    Comment remplir les champs GitHub Actions ?
    • Mode démo : cochez pour simuler la compilation localement. Décochez pour compiler réellement sur les serveurs macos-latest de GitHub.
    • Dépôt GitHub : créez un dépôt vide sur GitHub et indiquez votre-pseudo/nom-du-repo (ex: alex/mon-app-ios).
    • Branche : généralement main (vérifiez le nom de la branche par défaut de votre dépôt).
    • GitHub Token (PAT) : allez dans GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic), générez un token en cochant les cases repo et workflow, puis collez-le ici.
